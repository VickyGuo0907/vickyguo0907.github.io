01Proof of concept + article

Config-driven ML pipeline

A reusable machine-learning pipeline on Airflow, MLflow, FastAPI, and Docker. Adding a dataset takes a new config folder, not new code — three demo pipelines (hospital readmissions, gene expression, energy load forecasting) run on the same codebase.

Judgment call: an early version scored a test R² of ~0.22. I traced it to a field that was really a proxy for the target, removed it, and reported the honest ~0.05–0.07 instead.
